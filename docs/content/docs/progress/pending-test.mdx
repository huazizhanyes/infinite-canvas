- 画布参考音频配音：上传 WAV/MP3 后直接在该音频节点输入文案生成，或把上传音频连接到空配音节点后生成，都应显示“参考音频”而非强制选择音色库，并使用该音频的声音合成；断开参考音频后恢复音色库选择。需分别验证 Speech 与 VoxCPM2、刷新后重试、跨设备媒体恢复、他人媒体 ID 拒绝访问及本地文件未同步时的明确错误提示。
- 闪帧无限画布品牌：浏览器标签显示“闪帧无限画布”，favicon 使用素材网 Logo；画布首页标题同步显示“闪帧无限画布”，浅色/深色主题和刷新后均保持。
- 无限画布选择与平移：默认光标为选择箭头，空白区域左键可执行选择/框选；按住空格时光标变为抓手并可拖动画布，松开恢复箭头；底部工具栏按钮可在选择工具和移动工具间切换，中键平移仍可用。
- 画布节点成组：选中多个节点后点击工具栏“组”应按节点包围盒创建组并自动归属，未选中节点时仍可创建空组；`Ctrl+G`/`Cmd+G` 与按钮行为一致，撤销/重做和刷新后组关系保持；组内颜色控件可修改组背景色并持久化。
- 图片/视频节点输入区：图片节点提示词输入区高度约为 `144px`、视频节点约为 `176px`，输入文字和占位提示为较大的 `13px`；文本、音频节点输入区保持原有尺寸。
- 框选清理节点 UI：节点工具条或图片/视频输入面板打开时，从空白区域按下并框选，旧节点的选中框、悬浮工具条和输入面板都应立即隐藏，松开后不应自行恢复。
- 我的资产图片恢复：保存带 `storageKey` 的画布图片后刷新页面，“我的资产”卡片、资产详情、资产选择弹窗和画布 `@` 引用缩略图都应优先显示 IndexedDB 本地图片，不受旧 OSS 封面地址失效影响；20 MB、5504×3072 等大图同样应正常显示和下载。
- 画布图片来源：点击底部导入按钮应弹出“本地上传 / 我的资产”两个选项；选择本地上传保持原多文件导入流程，选择我的资产默认展示图片列表，点击后应在画布中心创建可预览、可生成、可下载的图片节点。
- 画布图片来源菜单：打开“本地上传 / 我的资产”菜单后，点击画布空白、节点或工具栏其它区域应立即关闭；点击菜单内部及两个来源选项仍应正常响应。
- 画布图片放大：本地 IndexedDB 中存在图片 Blob 时，即使节点显示地址为跨域 OSS URL，也应正常完成放大并创建新图片节点；本地 Blob 缺失且远端地址失效或未开放 CORS 时，应显示明确失败提示且控制台不再出现未处理的 Promise 异常。
- 公共会员弹窗：画布首页和具体画布的钻石入口应在当前页面打开素材网同款全屏会员弹窗，不跳转路由；顶部品牌/账户黑色条及其边框不再出现，关闭按钮、套餐购买、价格详情定位与三次高亮保持正常。素材网主页和素材页入口应使用同一款紧凑钻石按钮。
- 会员权益文案：会员卡应显示“创作智能体永久免费使用”和“Canvas 文案模型永久免费使用”；“去使用”应从素材网和画布嵌入场景都跳转到 `/write/` 顶层页面。
- 会员文本权益：白银、黄金、钻石账号在 Canvas 与 DeepWrite 调用任意 LLM 时均应显示“永久免费使用”且钱包不扣费，即使旧等级规则关闭了文本免费或限制了适用模型；普通账号仍应按真实用量计费。会员卡的永久图片/配音赠送额度应位于套餐权益内并高亮展示，钻石入口显示“会员中心”。
- 资产提取节点：从工具栏创建后应初始化独立正文记录，支持最多 30,000 字小说/文案，并可选择文本模型、图片模型、画面风格、画幅比例和图片质量，默认 `3D漫风格` 与 `16:9`；分析完成后按人物、场景、道具顺序在右侧每列纵向排列 5 个资产节点，超出后向右换列并自动连线，重复分析更新原节点并重新整理布局，本次未识别资产只标记不删除。
- 资产提取重做确认：已有资产时点击“提取资产”应先确认；确认后旧资产归档、旧资产节点移除，再按最新正文重新提取，取消不得发起分析。
- 资产展示与生图计费：人物资产描述应只保留干净、健康、常规服装的通用基础形象，泥泞、血污、伤势、肿包、临时表情和动作不得进入基础描述；人物图片继续使用左侧特写加正面/侧面/背面三视图。资产节点左侧可编辑名称、视觉描述和生图提示词，右侧显示待生成、生成中、失败和图片结果；单张及批量生图应使用提取节点选定的图片模型、画幅和质量，生成按钮旁显示单张图片报价，提交前使用报价令牌，按每张图片独立预扣、成功结算、失败退款，并正常写入 `canvas_script_image_batches`、`canvas_script_asset_images`、`plug_image_tasks` 与钱包账单日志，普通画布图片计费保持不变。
- 资产图片尺寸：选择 `16:9` 时人物三视图布局保持不变，但发送到号池渠道的 `size` 应为 `1024x576`；`1:1`、`3:4`、`4:3`、`9:16` 也应分别发送对应像素尺寸，确认 `api.hzzy.top` 任务请求与最终图片尺寸一致。
- 资产图片预览：点击资产图片可打开大图弹窗，右上角关闭按钮和点击遮罩均可关闭，不应触发画布拖动或缩放。
- 资产图片预览交互：资产节点图片单击不打开预览，双击才打开大图；图片和视频生图输入框中的长文本可使用内部滚动条滚动，不得触发画布缩放。
- 资产图片复用：资产图片大图支持滚轮及按钮缩放、恢复和下载；节点右下角可下载、保存到“我的资产”及创建相连的普通图片节点。重复保存同一提取资产时应更新已有条目，派生图片节点编辑后不得自动覆盖原资产。
- 资产资源提及：生图和生视频提示词输入 `@` 后应同时出现画布资源与带“我的资产”来源标识的本地图片/视频资产；选中后显示缩略图标签，只有提示词中实际选择的资产才计入报价并作为参考资源提交，同名资产应显示可区分的序号。
- 视频引用提示词：选择图片引用后，编辑器值、节点历史记录、Seedance/画布视频任务请求均应保留 `@图片1`、`@图片2`；旧版已保存的 `图片1拿着铲子图片2` 生成或重试时应恢复为带 `@` 的引用格式。
- 资产库提及菜单：`@` 菜单主列表最后一行应为“资产库”，鼠标悬停后在右侧展开图片/视频资产二级菜单；资产名称和描述过长时单行省略，不得撑宽菜单，移入二级菜单选择资产时不能触发画布拖动。
- 资产提及触发：`@` 可以直接紧跟中文或英文文字触发，不要求先输入空格；选中资产后仍自动补一个空格，便于继续输入。
- 视频模型占位：视频模型下拉中应在可用模型后显示禁用的 `Seedance 2.0 · 即将上线` 与 `HappyHorse · 即将上线`，点击不可切换或提交。
- 图片/视频默认提示：空的生图输入框应显示“上传参考图、输入文字或 @ 主体，描述你想生成的图片。”，空的视频输入框应显示参考图、音频、`@` 引用和拖拽上传引导；输入框聚焦后提示立即隐藏，失焦且仍为空时恢复显示。
- 画布输入体验：资产提取画幅选项只显示矩形图标和 `16:9`、`9:16` 等比例，不显示像素尺寸；在图片/文本/视频提示词中输入或选择 `@图片` 后，光标应保持在插入位置并可立即继续输入；资产提取正文、资产描述和资产提示词不显示放大按钮且布局不变，剧本正文、普通分镜提示词和智能体长文本仍可放大编辑。
- 节点精简：工具栏、双击创建菜单、连线创建菜单、侧栏筛选和节点注册中均不再出现“生成配置”或“九宫格分镜”；打开含旧节点的项目时，生成配置节点、九宫格节点、九宫格图片组、镜头图片及相关连线应被直接移除，普通文本、图片、视频、配音、分镜脚本和资产提取保持正常。
- MiniMax H3 画布视频：模型区只显示 MiniMax H3 与“不卡人脸”，不得出现线路选择、其他模型、清晰度/价格副标题或积分；设置弹层应为加宽紧凑布局，秒数使用滑块；视频节点下方提示词面板宽度应与图片节点一致、输入高度保持视频所需空间，在画布缩放后仍可清楚阅读。空的视频输入框应显示占位引导，聚焦后隐藏，失焦且为空时恢复。文生视频禁止图片但允许 0-3 个音频，全能参考要求 1-9 张图片并允许 0-3 个音频，两种模式都不得提交参考视频；480p/768p/1080p/2K、16:9/9:16、5-15 秒整数和 10000 字提示词需前后端一致校验。
- MiniMax H3 人民币计费：普通、白银、黄金、钻石账号应读取各清晰度独立售价，报价提示展示专属单价、普通原价、每秒节省和预计扣款；提交前重新报价，价格发布后旧报价被拒绝，已预占/已排队/已提交任务继续使用价格快照并按请求时长结算。
- MiniMax H3 队列与归档：用户并发默认 1/2/4/8、队列上限 3/6/12/20、线路总并发 8；多实例调度不得超发，取消未提交上游的排队任务应立即释放钱包冻结。成功结果必须完成 OSS 归档后才显示完成，归档失败可重试，参考图片、参考音频和生成视频不得被旧 30 天清理任务删除。
- AI 商业充值：画布用户资产菜单应从后台发布接口读取套餐，支持自定义充值、套餐快照、微信二维码支付和重复回调幂等；支付后钱包、通用图片额度、永久配音字符、累计充值等级、文本免费和视频折扣应同步刷新。需在专用测试数据库执行迁移并完成退款回收与已消费权益人工审核流程。
- 首屏与画布存储优化：首次打开画布库不应提前下载画布编辑器、Agent、配置面板或 CodeMirror；打开对应功能后应正常加载。已有旧版 IndexedDB 画布首次启动后应自动迁移为按项目分片存储，项目列表、节点、连线和视口不丢失；流式文本生成、高频任务进度及立即返回/刷新后最后一次编辑仍应保存。
- 画布紧凑界面：图片、文本、视频、音频、组、剧本与插件节点应统一使用细边框和小圆角，选中节点显示清晰白色描边；生成输入面板始终位于节点下方并避让底部工具栏，保存状态正确区分待保存和实际写盘；工具条、模型参数与设置弹层在 100%–300% 缩放下文字不溢出，深浅主题均保持清晰层级。
- 画布缩放与平移：高频滚轮和触控板缩放应保持连续、缩放中心不漂移，滚动期间只更新 DOM 预览并在停止后提交一次视口；按住空格后可从节点非交互区域拖动画布，指针取消或窗口失焦后光标和拖动状态应恢复。
- Seedance 2.0 服务端视频：验证动态模型能力、文生视频/图生视频/首尾帧及参考视频/音频素材限制；创建后节点应保存 `videoTaskId`，停止等待或关闭桌面不取消后端任务，重新进入后可恢复；成功节点必须保存 HTTP(S) URL 与 `serverStorageKey`，不得写入 `media_files` IndexedDB，清理本地缓存或换电脑后仍可播放。
- 图片生成参数：画布图片节点只能选择 1 至 5 张，独立图片工作台可选择 1 至 10 张；固定比例应向模型传递对应的实际像素尺寸，`auto` 保持原值。
- 媒体生命周期：用同一 `storageKey` 替换图片、音频或视频后旧对象 URL 应被回收；删除和清理媒体后内存缓存与 IndexedDB Blob 同时移除，重复清理不报错，当前项目、撤销历史和任务快照仍引用的媒体不得丢失。
- 画布空间索引与渲染：新建、连接、折叠、拖动、撤销、保存和刷新行为保持不变；500 节点、2000 连线下持续缩放、平移、选择和打开节点面板时，只查询视口附近的节点与连线，未变化的连线路径不应重复计算，交互期间模糊、阴影和过渡应临时降级并在结束后恢复。
- 桌面 Agent 隐藏：开发嵌入和生产嵌入均不显示顶部 Agent 按钮或右侧面板，不自动连接 Agent，不发起 Agent SSE、WebSocket 或画布上下文同步；插件系统、普通 AI 节点生成和桌面任务中心保持正常。
- 嵌入画布可靠保存：编辑节点后工具栏应依次显示“保存中/已保存”；立即返回画布库、返回创作主页、重载 iframe 或关闭桌面窗口后重新进入，最后一次编辑仍应存在；服务端不可用时最多等待 3 秒并显示未确认保存提示，不能永久阻塞退出。
- 大画布连线裁剪：在视口内、端点位于视口外但曲线穿过视口、折叠批次和拖动预览四种场景下连线都应正确显示；平移到远处后原区域的 SVG 连线应卸载。
- 创作平台任务快照：嵌入模式下开始、完成、失败和取消画布生成后，桌面任务中心“无限画布”标签应在 5 秒内同步当前及最近记录；iframe 重载或超过 15 秒无心跳后旧快照应清空，取消和重试仍只在画布内操作。
- 独立分镜脚本节点：从文本节点全文或选区创建，节点仅保存分镜 ID、来源节点 ID 和来源范围，刷新后能恢复后端数据且不能直接复制。
- 分镜分析：验证简略/标准/细致密度、16:9 默认画幅、目标总时长、两阶段异步轮询、成功替换与失败保留旧结果；每个镜头保留原文依据、对白/旁白和图片/视频提示词。
- Token 计费：预估不扣费，确认后预扣，成功按实际 usage 结算，失败/取消/重启释放，重复 request_id 不重复扣费。
- 分镜工作区：桌面三栏、移动端 Drawer，场景导航、镜头编辑、自动锁定字段、复制/拆分/合并、导出 Markdown/CSV/JSON。
- 分镜组件：默认显示摘要，展开后在画布节点内部显示顶部参数、场景标签、镜头卡片和内联编辑，不应打开右侧 Drawer，节点展开/收起和画布拖动不应互相干扰。

# 待测试

- 画布资源引用：从视频节点右侧连接图片后，视频节点的 `@` 菜单应出现该图片，选中后生成请求应携带图片参考；从任意方向连接的文本、图片、视频和音频资源均应保持引用去重。
- 画布 `@` 菜单定位：在画布缩放、平移、滚动页面及输入框靠近视口边缘时打开菜单，候选列表应贴合输入框并完整显示在可视区域内。
- 画布媒体下载：图片、视频和音频优先从本地持久化 Blob 下载；本地 Blob 不存在时使用远程地址，HTTP 失败应显示下载失败提示且不生成错误文件。
- 画布批量上传：工具栏选择多个图片/视频/音频后应全部创建节点并以网格排布；节点上的上传/替换入口仍只替换当前节点的单个文件。

- 资产提取流程：资产节点无图片时应同时显示“上传图片”和“生成资产图”；上传、替换、刷新后图片和媒体元数据应保持，生成图片可继续预览、下载、保存到我的资产并创建普通图片节点。
- 资产提取分镜草稿：点击“生成分镜并创建视频草稿”应创建或更新一个分镜文本节点和一个空视频节点，自动连线正文、分镜和已有资产图片；视频节点提示词应包含场景、人物关系、镜头语言、节奏、声音及图片编号，且不会自动提交视频生成。点击视频生成时，连接的资产图片应真正作为参考图提交。
- 资产提取批量确认：批量生成报价应按全部资产张数计算，确认弹窗显示总张数和预计费用；取消确认不得提交任务，分批提交时每批使用匹配数量的新报价令牌。
- 资产正文版本：分析完成后修改正文应提示当前资产来自旧版本，并阻止直接创建分镜草稿，重新分析后提示消失。

- 配置入口精简：点击右上角配置按钮只显示“偏好设置”页签，不显示渠道管理、新增渠道、编辑渠道或删除渠道入口；默认模型、画布张数、音频偏好和系统提示词仍可保存，系统自动注入的模型调用不受影响。

- 画布拖动性能：在包含较多节点和连线的画布中持续平移画布、拖动单个/多个节点和组，预览应保持流畅且连线同步移动；松手后视口、节点位置、分组吸附、撤销历史、本地保存和云同步应正常生效，拖动过程中不应周期性发起保存请求。

- 创作平台外层侧栏：具体画布中点击返回先进入画布库，画布库中点击返回再进入创作平台主页；画布/资产入口应从外层打开对应内侧面板，内侧默认不再显示重复入口。
- 画布库增强背景：技术边框、动态扫描和网格漂移仅出现在画布库，编辑画布及其它页面背景不变，并遵循减少动态效果系统设置。

- 画布界面精简：顶部不显示版本号和 GitHub；画布库首页使用独立背景；进入画布后左侧画布/资产面板默认收起，两个入口均可展开且展开后可再次收起。

- 创作平台嵌入模式：顶部导航不显示“返回主页”，独立运行画布时该入口仍正常显示。

- 文本模型 key：前端渠道模型值带有 `渠道 ID::模型名` 时，画布文本预估和生成请求应只向后端传递模型名；需验证 `sucai-canvas::deepseek-v4-flash` 不再被错误判定为不存在模型。
- 文本节点工作台：工具栏应显示“AI处理”“编辑内容”“生成媒体”；AI 处理支持续写、润色、扩写、缩写、总结、翻译和自定义指令，原文不被覆盖，成功结果生成右侧新文本节点并自动连线。
- 文本节点选区与编辑：全文/选区处理范围应正确，编辑态显示字符数和行数，`Ctrl/Cmd + F` 可查找替换，`Ctrl/Cmd + S` 可保存文本资产，长文本和移动端不溢出。
- 文本 Token 计费：`POST /canvas/v1/responses/estimate` 只读返回输入/输出/总 Token 和余额；确认前不扣费，确认后预扣并按实际 usage 结算，失败、取消和重复请求分别释放或幂等。
- 文本媒体入口：图片、配音、视频菜单均可从文本节点创建对应预填充节点并自动连线；创建节点本身不扣额度，确认后才生成，图片/音频额度不足和视频不可用时显示明确原因。
- 文本来源恢复：刷新画布后新文本/媒体节点的 `sourceNodeId`、处理动作、处理范围和请求 ID 保持，失败节点可重试且原文本保持不变。

- 剧本集节点：工具栏和双击创建菜单均应能新建剧本集并默认展开为 `920×700` 画布内组件；收起后恢复 `360×210` 摘要，刷新、撤销和重做后保持展开状态，不再显示右侧 Drawer。
- 剧本集内嵌工作区：剧集正文、统一生图设置、资产筛选与批量生图、待确认处理均应在节点内部工作；输入、滚动和按钮操作不触发画布拖动或缩放，资产结果必须落到发起任务的剧本集分组。
- 剧本集剧集：只能逐集手动新建和粘贴正文，单集不得超过 30,000 字符；刷新和跨设备后正文、顺序、标题及当前分析版本应从后端恢复，不得写入画布节点 JSON。
- 剧本资产分析：应只提取人物、场景和重要道具，普通背景物不得进入资产库；需验证别名复用、同名身份冲突、高置信度自动复用、中置信度待确认、换装/战损/昼夜变体及三种人工确认操作。
- 剧本资产分析异常返回：模型返回合法 JSON 时保持原解析；返回数组对象漏写 `{}`、但字段结构仍完整时应自动修复并继续提取；字段截断、括号不匹配或非资产结构仍应显示明确失败并允许重新分析。
- 剧本重新分析：新分析失败时旧结果保持可用；成功后保留人工编辑和人工合并，只更新本集引用，无引用的纯 AI 资产归档，已有图片或人工编辑资产不得自动归档。
- 剧本 Token 计费：分析前应一次预扣抽取与匹配预计 Token，成功按两阶段实际 usage 确认并释放差额，失败或服务重启中断应释放预扣；重复请求不得重复分析或扣费。
- 剧本资产生图：剧本集画风、画幅和质量应作用于人物/场景/道具提示词；批量确认显示准确张数和余额，成功结果成为资产封面并按三类创建普通画布图片节点，刷新或跨设备恢复不得重复落节点，失败任务按现有图片规则退款。
- 剧本资产生图过程：点击开始生成后应立即在画布对应分组创建加载占位节点；任务轮询期间节点保持加载状态，成功后原位显示图片，失败或取消后显示失败状态；人物图片应优先呈现白底脸部特写、正面全身、侧面全身、背面全身的横向角色设定表。
- 剧本资产生图选择与进度：首次打开资产页不应自动选中全部资产；“只选无图”只选没有封面的资产/变体，“全选当前分类”只选择当前筛选结果，“清空选择”应清除选择。确认框需明确每个资产/变体消耗一张图片额度，工作区内展示批次进度、成功/失败数量和每个资产的生成中/成功/失败状态。
- 剧本集默认画幅与场景约束：新建剧本集和旧默认 1:1 剧本集均应使用 16:9 生图；场景图片不得出现人物、人体、脸部、路人或剪影。
- 剧本集删除与复制：复制入口应隐藏，删除需二次确认并软删除后端剧本集，同时移除该剧本集生成的画布分组和图片节点；不同用户、不同剧本集之间不得查询或复用资产。
- 用户资产与 Token：配置 `VITE_SUCAI_CANVAS_API_BASE` 与 `VITE_SUCAI_API_BASE` 后，画布首页和项目页右上角均应显示用户头像；点击后应正确展示图片张数、文本 Token、音频字符和“视频暂未开通”，桌面使用 Popover、移动端使用 Drawer。
- 用户资产充值：永久配音会员的音频额度应显示“无限字符”，其他用户显示实际字符余额；“去充值”应在新窗口打开配音订阅页。图片额度“去充值”应打开与素材网一致的额度弹窗，套餐、二维码支付、到账轮询和余额刷新均应正常。
- 文本 Token 计费：首次访问按免费/普通/超级用户获得 1 万/10 万/30 万月赠 Token；文本生成应预扣并按输入与输出实际 Token 确认，失败不扣费，重复请求和重复支付不得重复扣除或到账。
- Token 充值与明细：用户应能查看启用套餐、创建微信支付订单、支付到账后自动刷新余额和流水；没有启用套餐时显示明确空状态。
- 管理端 Token 管理：运营中心应出现账户、流水、订单、套餐、每月赠送五个 Tab，人工赠送/调整必须填写原因，扣减不得造成充值余额为负，月赠修改从下月生效。

- 提示词库入口：`VITE_SHOW_PROMPT_LIBRARY_UI=false` 时画布节点、生图工作台和视频工作台不显示提示词库按钮且不能打开选择弹窗；改为 `true` 后入口应恢复。
- Agent 入口：`VITE_SHOW_AGENT_UI=false` 时顶部导航和画布内不显示 Agent 状态或按钮，右侧 Agent 面板不挂载且不自动连接；改为 `true` 后原有入口和面板应恢复。
- 画布生图设置：宽高比不再显示 1:1/16:9/9:16 的 2K、4K 预设，生成张数只显示 1–5；旧配置或节点即使保存了更大张数，实际单次生成也不得超过 5 张。
- 画布音频设置：桌面端应以音色库和输出设置双栏展示，窄屏自动切换为单栏；长音色名不得溢出卡片，音色列表应独立滚动，搜索、分类、选择、试听、格式、语速和情绪指令功能保持正常。
- 顶部导航：画布首页应直接展示“我的画布”列表并高亮对应导航项；最左侧“返回主页”应跳转到 `VITE_SUCAI_HOME_URL`，桌面和移动导航不再显示品牌、生图、视频、提示词库入口，Header 右侧不再显示文档图标，原 `/canvas`、`/image`、`/video`、`/prompts` 路由仍可直接访问。
- 素材网画布后端 Agent：未登录用户不得调用 Agent 接口；登录用户只能访问自己的项目、会话、消息和轮次，且不能借 Agent 绕过画布会员入口或访问其他用户项目；删除画布后关联会话应一并清理。
- 素材网画布后端 Agent：管理端 LLM 模型页应可维护“支持工具调用”和“支持图片理解”，画布配置只能选择启用、允许画布、纯文本、OpenAI Chat 格式且能力匹配的主模型与可选视觉模型；Agent 未启用或主模型未配置时前端应给出明确状态。
- 素材网画布后端 Agent：需验证新建、切换、删除和跨设备恢复会话，以及 `turn_started`、`assistant_message`、`tool_call`、`usage`、`done`、`error`、`heartbeat` SSE 事件；同一会话不得并行运行两个轮次，重复 `clientTurnId` / `callId` 不得重复执行。
- 素材网画布后端 Agent：所有 `canvas_apply_ops` 写入和计费生成必须展示确认卡，拒绝后画布不得变化且不能自动重试同一操作，批准后应复用现有画布操作、可撤销，并把最新快照回传后继续回答。
- 素材网画布后端 Agent：需验证普通 DeepSeek 回答、合法与无效工具参数、六次模型调用上限、50 个操作上限、五分钟超时、停止取消、上游失败和服务重启后的遗留轮次恢复；模型、渠道、耗时及 token 应记录但不得扣减文本额度。
- 素材网画布后端 Agent：配置视觉模型后应能分析远程图片及最多三个已选本地图片节点；未配置视觉模型、图片过大、Blob 无法解析或节点内容包含提示注入时应安全失败，不得覆盖 Agent 系统规则。
- 素材网商业构建设置 `VITE_CANVAS_AGENT_MODE=backend` 与 `VITE_SHOW_CANVAS_PLUGIN_UI=false` 后，应隐藏插件管理、扩展节点按钮和插件创建菜单，但已启用插件及已有插件节点仍能加载；独立开源版应继续显示插件入口并使用原本的本地 Codex Agent。
- 画布模型目录新增能力分类：应返回一个管理端主生图模型、全部启用且允许画布使用的纯文本模型，以及管理端启用的 Speech/VoxCPM2 音频模型；Voice Design 不应出现在文本模型列表。
- 模型显示名：文本/图片/音频模型选择器应优先显示接口返回的 `display_name`，不显示内部 ID，也不追加渠道括号；重复模型名来自不同渠道时仍能正常选择和提交。
- 画布文本节点支持选择全部可用纯文本模型，后端应严格按提交的模型 ID 调用对应 AI 服务渠道，图片、配音和 Voice Design 模型不得调用文本代理。
- 画布工具栏新增“配音”节点，上传音频流程保持不变；配音节点需验证手动文本、连接上游文本、Speech/VoxCPM2 切换、音色搜索/试听、语速、格式、情绪/控制指令、生成、取消和失败重试。
- 画布配音创建后每 3 秒轮询独立任务；分别验证 Speech 和 VoxCPM2 成功播放、刷新后按任务 ID 恢复、云同步后仍使用稳定远程 URL，以及用户不能查询或取消其他用户任务。
- 画布配音音色库仅应返回公共音色、当前用户私有音色和用户可访问音色，且必须存在参考音频；需验证 `displayName` 展示、搜索、头像试听、我的音色、全部收藏及按收藏夹筛选，魔音与不可访问音色不得返回或用于创建任务。
- 画布配音音色面板改为搜索、全部/我的/收藏分段筛选、收藏夹横向筛选和三列音色网格；需验证深浅主题下筛选清晰、长名称不撑开布局，切换筛选不会意外改变当前音色。
- 画布图片、文本、视频、配音、失败重试、局部编辑及刷新恢复的配音任务成功后播放与素材网生图一致的完成提示音；批量生图一次操作只应提示一次，失败或取消不应提示。
- 画布配音成功落盘后只扣一次字符额度，并写入 `canvas_speech` / `canvas_voxcpm2` 日志；生成失败或取消不得扣费，旧 `/online/speech`、`/online/voxcpm2/speech` 和原音色接口请求响应需保持不变。
- 素材网登录用户进入 AI 画布后，可自动加载管理端配置的生图渠道，并通过素材网后端生成图片。
- 素材网画布生图创建接口改为立即返回任务 ID，前端每 3 秒轮询任务状态；需验证生成成功、渠道失败、用户取消和十分钟超时四种状态。
- 素材网画布文本节点改为读取管理端独立选择的 InkOS LLM 模型，并通过素材网后端代理调用；需验证纯文本、参考图理解、Responses、Chat Completions 和 Anthropic 渠道。
- 素材网画布项目和图片、视频资产保持 IndexedDB 本地优先保存，并在登录后自动同步到用户私有云端；需验证刷新恢复、双设备按更新时间合并、离线编辑后重连上传、删除不被旧设备恢复。生图/视频历史记录不参与同步。
- 画布节点插件系统：内置节点（图片/文本/视频/音频/组/剧本集）由统一注册表管理，创建菜单由注册表动态生成；需验证六种内置节点的创建、渲染、缩放、连线和小地图颜色，普通节点作为生成输入的行为与之前一致，其余节点类型均为插件。
- 画布节点插件系统:左上菜单新增「节点插件」,可通过 URL 安装远程插件、启用/禁用、更新、卸载;安装时有安全警告说明插件代码在页面内执行、可访问本地数据。可用 `/plugins/sticky-note.js` 安装便利贴节点验证:换色、编辑、「衍生文本节点」(演示 applyOps 增节点+连线)。
- 画布节点插件系统:示例插件 Markdown(编辑/渲染)、HTML(沙箱 iframe 渲染,支持 {{input}} 注入上游文本)、SVG(渲染/编辑,可取上游文本 SVG 源码)、3D 全景(three.js CDN 动态加载,可从上游图片节点取全景图并拖拽查看);均为远程插件,需分别安装 `/plugins/markdown.js`、`/plugins/html.js`、`/plugins/svg.js`、`/plugins/panorama.js` 后验证创建、渲染、编辑及与上游节点的交互。

- 画布节点插件系统:每个插件为 `plugins/canvas/<name>/` 独立目录(各自 package.json + esbuild + src + README,互不耦合),`npm run build` 产物落到 `dist/<name>.js` 并同步到 `web/public/plugins/`;需验证各插件可独立构建与安装。
